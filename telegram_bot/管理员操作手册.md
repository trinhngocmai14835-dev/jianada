# Telegram TRC20-USDT 收款机器人操作手册

## 一、启动机器人

双击运行：

```bat
telegram_bot\start.bat
```

看到 `Bot 启动中...` 就表示机器人已运行。窗口关闭后机器人会下线。

## 二、客户充值流程

客户发送 `/start` 后会看到：

- 收款网络：TRC-20 / TRON
- 收款地址：来自 `.env` 里的 `USDT_WALLET`
- 金额：1 USDT = 6.8
- 按钮：复制地址、提交 TxHash、我的充值

客户可以点“复制地址”复制收款地址。转账完成后，把 64 位交易哈希 TxHash 发给机器人。机器人会查询链上记录，只要确认是转入你收款地址的 TRC20-USDT，且金额大于 0，就会回复客户“充值已确认”。

## 三、你会收到什么通知

客户提交 TxHash 并验证成功后，你会收到 Telegram 通知，包含：

- 客户 Telegram 用户和 ID
- 到账金额
- 付款地址
- 收款地址
- TxHash
- 区块时间

机器人也会后台监听你的收款地址。如果有新的 TRC20-USDT 入账，即使客户还没提交 TxHash，你也会收到一条“USDT 到账通知”。

## 四、常用命令

| 命令 | 用途 |
|------|------|
| `/start` | 显示充值地址、汇率和按钮入口 |
| `/recharge` | 让客户提交 TxHash |
| `/myrecharges` | 客户查看自己的充值记录 |
| `/recent` | 管理员查看最近 20 条客户提交的充值记录 |
| `/myid` | 查看自己的 Telegram ID |

## 五、配置文件

第一次使用时，把 `telegram_bot\.env.example` 复制成 `telegram_bot\.env`，然后填真实配置：

```env
BOT_TOKEN=你的机器人Token
ADMIN_ID=你的Telegram数字ID
USDT_WALLET=你的TRC20-USDT收款地址

# 可选：TronScan API Key，频繁查询时建议配置
TRONSCAN_API_KEY=

# 可选：后台到账监听
PAYMENT_WATCH_ENABLED=true
PAYMENT_WATCH_INTERVAL_SECONDS=60
PAYMENT_WATCH_LOOKBACK_MINUTES=180
PAYMENT_WATCH_SKIP_OLD_DEPOSITS=true
```

## 六、注意事项

- 只支持 TRC20-USDT。
- 页面显示汇率：1 USDT = 6.8。
- 客户如果使用 ERC20、BEP20 或其他网络，机器人不会确认到账。
- 首次启动默认会把最近历史入账标记为已读，避免旧交易重复通知你。
