# 自动下单系统Pro — 管理员操作手册

---

## 一、启动机器人

双击运行 `telegram_bot\start.bat`，看到 `Bot 启动中...` 即正常运行。
关闭窗口 = 机器人下线，需要一直开着。

---

## 二、日常销售操作

### 查看待审核订单
```
/pending
```
客户付款后如果链上自动验证失败，会推送通知给你，同时可用此命令查全部待处理订单。点消息里的按钮「✅ 确认发放」或「❌ 拒绝」即可。

### 手动给线下客户生成授权码（你自己复制发给他）
```
/issue <机器码> <套餐>
```
示例：
```
/issue ABCD1234EFGH5678 7
/issue ABCD1234EFGH5678 30
```

### 直接发授权码到客户 Telegram（客户必须跟机器人聊过天）
```
/send <用户ID> <机器码> <套餐>
```
示例：
```
/send 123456789 ABCD1234EFGH5678 7
```

**套餐代号对照：**

| 代号 | 名称 | 天数 | 零售价 |
|------|------|------|--------|
| `trial7` | 试用周卡 | 7天 | 免费 |
| `7` | 周卡 | 7天 | 60U |
| `30` | 1个月 | 30天 | 240U |
| `90` | 3个月 | 90天 | 680U |
| `365` | 12个月 | 365天 | 2000U |

## 三、代理管理

### 添加代理
```
/addagent <用户ID> <备注>
```
示例：
```
/addagent 123456789 A代理-张三
```
> 代理在机器人发 `/myid` 可查到自己的用户ID

### 给代理充卡
```
/topup <用户ID> <套餐代号> <数量>
```
示例：
```
/topup 123456789 trial7 10    ← 充10张试用周卡
/topup 123456789 7 20         ← 充20张正式周卡
/topup 123456789 30 5         ← 充5张月卡
```
充卡后机器人自动通知代理。

### 查看所有代理及库存
```
/agents
```

### 查看某代理的发卡记录
```
/agentlog <用户ID>
```

## 四、代理操作流程（给代理说明用）

1. 发 `/myid` 把 ID 报给你
2. 发 `/mybalance` 查自己库存
3. 发 `/genkey` → 输入客户机器码 → 选卡类型 → 授权码自动生成
