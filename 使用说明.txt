================================================================
           自动下单系统 Pro  —  使用说明
================================================================

【系统要求】
  - 操作系统：Windows 10 / 11 / Server 2019+（64位）
  - 需要安装 Google Chrome 浏览器
  - 不需要安装 Python 或其他运行环境，双击 EXE 即可运行

================================================================
一、首次安装
================================================================

1. 将 "自动下单系统Pro.exe" 放到任意目录（建议新建专属文件夹）

2. 双击运行，首次启动会弹出提示框：
   "正在自动安装 Chromium 浏览器驱动，请稍候..."
   等待约 3~5 分钟（下载约 150MB）直至进度框消失

3. 驱动安装完成后，程序会自动启动后台服务

4. 打开浏览器（推荐 Chrome 或 Edge），访问：
   http://127.0.0.1:8080

5. 首次访问会跳转到【授权激活】页面

================================================================
二、授权激活
================================================================

1. 激活页面会显示本机的【机器码】（16位字母数字），点击【复制】

2. 将机器码发给管理员，说明需要的授权天数

3. 管理员生成授权码后发给你（授权码较长，完整复制）

4. 将授权码粘贴到输入框，点击【激活授权】

5. 显示"激活成功"后自动进入主界面

注意：
  - 授权码与机器码绑定，换电脑需重新申请
  - 到期后系统会提示重新激活，不影响历史配置

================================================================
三、功能一：自动下注（三球9粒）
================================================================

适用场景：自动登录账号，按策略每期自动下注。

操作步骤：

1. 点击左侧菜单【自动下注】

2. 填写参数：
   ┌─────────────────────────────────────────┐
   │ 入口网址    填写下注平台网址               │
   │ 安全码      平台的安全验证码               │
   │ 账号列表    可添加多个账号（账号/密码/端口）│
   │ 单注金额    每个号码投注的金额（元）        │
   │ 每球号码数  每期每球投几个号码（1~9）       │
   │ 开始时间    每天几点开始自动下注（小时）    │
   │ 结束时间    每天几点停止自动下注（小时）    │
   │ 止盈        当日累计盈利达到该值自动停止    │
   │ 止损        当日累计亏损达到该值自动停止    │
   │ 赔率        平台赔率（用于盈亏计算）        │
   │ 退水比例    平台退水（用于盈亏计算）        │
   └─────────────────────────────────────────┘

3. Telegram 通知（可选）：填写 Bot Token 和 Chat ID 可接收下注通知

4. 点击【保存并启动】，右侧日志框会实时显示运行状态

5. 需要停止时点击【停止】

================================================================
四、功能二：多账号跟投
================================================================

适用场景：监控主账号（采集账号）的投注记录，自动同步跟投到其他账号。

前置条件：
  - 准备好 Google Chrome 浏览器
  - 采集账号和跟投账号均需已在 Chrome 中登录

操作步骤：

【第一步：准备采集账号（主账号）】

1. 手动打开一个 Chrome 窗口，在地址栏输入以下命令启动（替换路径）：
   "C:\Program Files\Google\Chrome\Application\chrome.exe"
   --remote-debugging-port=9222
   --user-data-dir=C:\betting_chrome_9222

   （也可以在系统配置里填入"入口网址"，点启动后会自动打开主账号浏览器）

2. 在该 Chrome 窗口中登录采集账号

3. 登录后进入：报表查询 → 注单明细（BettingDetail 页面）
   系统会自动识别此页面并开始采集数据

【第二步：准备跟投账号】

1. 在系统页面【多账号跟投】→【跟投账号列表】中添加跟投账号
   填写 CDP 端口（如 9223、9224，不可重复）和跟投倍数
   （倍数：每注金额 = 客户该注金额 × 倍数，如 2=两倍、1=等额跟，支持小数）

2. 点击每个账号右上角的【打开浏览器】按钮，系统会自动打开对应端口的 Chrome

3. 在弹出的 Chrome 窗口中登录跟投账号

4. 登录后进入对应游戏的下注页面（即时注单 / 快三 等带倒计时的投注页面）
   页面上需要能看到倒计时数字

【第三步：启动跟投】

1. 配置参数：
   ┌─────────────────────────────────────────┐
   │ 入口网址      平台登录网址（可留空）      │
   │ 采集端口      主账号浏览器端口，默认 9222 │
   │ 刷新间隔      多少秒刷新一次注单，建议2~3 │
   │ 跟投账号列表  每个跟投账号的端口和倍数    │
   │ 开始窗口倒计时  超过该秒数时等待（默认120）│
   │ 封盘保护倒计时  低于该秒数停止跟投（默认35）│
   │ 赔率 / 退水   用于自动结算盈亏           │
   └─────────────────────────────────────────┘

2. 点击【保存并启动】

3. 系统运行流程：
   ① 自动连接采集账号浏览器
   ② 等待检测到注单明细页面
   ③ 检测跟投账号浏览器的倒计时
   ④ 倒计时进入投注窗口后，读取采集账号最新注单
   ⑤ 自动在跟投账号的投注页面填入对应号码并点击确认
   ⑥ 每期自动计算盈亏并在日志中显示

注意事项：
  - 采集账号浏览器必须停留在注单明细（未结明细）页面，不要切走
    （可在客户还没下注时提前打开空的未结明细页挂着，程序会一直等）
  - 跟投账号浏览器必须停留在带倒计时的游戏投注页面
  - 不要手动操作正在跟投的浏览器窗口
  - 镜像全跟：每个跟投账号都跟随客户的全部注单（不再均分号码），
    各账号金额 = 客户金额 × 各自倍数

================================================================
五、功能三：抢投
================================================================

适用场景：在投注窗口开放瞬间快速下注，抢先于其他人投注。

操作步骤：

1. 点击左侧菜单【抢投】

2. 填写目标游戏和下注参数

3. 确保对应的 Chrome 浏览器已打开并停留在下注页面

4. 点击【保存并启动】

================================================================
六、日常使用流程
================================================================

每天开始使用：
  1. 双击 "自动下单系统Pro.exe"（保持窗口开着，不要关）
  2. 打开浏览器访问 http://127.0.0.1:8080
  3. 按需打开采集/跟投账号的 Chrome 浏览器并登录
  4. 在系统页面点击【保存并启动】

结束使用：
  1. 在系统页面点击【停止】
  2. 关闭 "自动下单系统Pro.exe" 窗口即可

================================================================
七、常见问题
================================================================

Q：双击 EXE 没有反应 / 一闪而过？
A：右键 EXE → 以管理员身份运行。
   或检查杀毒软件是否拦截（加入白名单）。

Q：打开 http://127.0.0.1:8080 显示"无法访问此网站"？
A：EXE 程序必须保持运行（黑色命令窗口不能关）。
   等待约 5 秒后刷新页面重试。

Q：授权激活显示"机器码不匹配"？
A：授权码与电脑绑定。换了电脑需重新申请授权码。

Q：跟投启动后日志显示"未检测到倒计时"？
A：跟投账号的 Chrome 必须停留在含有倒计时的游戏投注页面
   （不是登录页、不是报表页，是能看到"距离封盘 XX:XX"的页面）。

Q：日志显示"未找到注单明细页"？
A：采集账号的 Chrome 必须停留在注单明细/BettingDetail 页面。
   如已在该页面请等待几秒后系统自动识别。

Q：跟投账号下注了但金额不对？
A：跟投金额 = 客户该注金额 × 倍数。检查跟投账号列表中的"跟投倍数"是否填写正确
   （倍数会随客户每注的实际金额自动换算，客户金额变了跟投金额也会变）。

Q：系统提示"Chrome连接失败"？
A：确保对应端口的 Chrome 已正常启动并完成登录。
   在系统配置页面点击【打开浏览器】可自动启动。

Q：采集账号超过15注但只跟了15注？
A：这是旧版本问题，新版本已自动设置显示999条记录，无需手动处理。
